# RomiCore SDK MQTT API仕様

このページでは、MIXIが開発した会話AIロボット「Romi」を制御するためのMQTT通信仕様を提供しています。

## できることの例

- Romiにツールを追加する
- Romiに発話させる
- Romiが配信するイベントを受信する

機能の一覧は AsyncAPI 仕様または RomiCore SDK を参照してください。

## スコープ

このドキュメントでは、Romiと通信するためのMQTTベースのインターフェースとして、以下を定義します。

- トピック構造
- メッセージカテゴリ
- ペイロード形式
- リクエスト/レスポンスのパターン
- イベントメッセージ
