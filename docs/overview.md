# 概要

この仕様は、MIXIが開発した対話型AIロボット「Romi」を制御するための、MQTTベースの通信インターフェースを定義します。

本仕様は、MQTT経由でRomiと通信するあらゆるクライアント実装を対象としています。  
実装がこの仕様に準拠していれば、公式SDKの利用有無にかかわらずRomiと連携し、制御できます。

## 目的

この仕様の目的は、Romi制御のための一貫性があり実装に依存しないインターフェースを提供することです。

これにより、異なるクライアント、アプリケーション、デバイスが同一のMQTTベースプロトコルでRomiと通信できます。

## 通信モデル

このインターフェースは、MQTT上のメッセージベース通信を中心に設計されています。

主なメッセージカテゴリは次のとおりです。

- **Request**  
  クライアントがRomiに対して、またはRomiがクライアントに対して動作の実行や情報の返却を要求するために使用します。

- **Response**  
  Romiまたはクライアントががリクエスト結果を返すために使用します。

- **Event**  
  Romiが状態変化、動作、その他の非同期更新をクライアントへ通知するために使用します。

## この仕様が定義する内容

この仕様では、以下を定義します。

- MQTTトピック構造
- メッセージカテゴリとその役割
- ペイロード形式
- リクエスト/レスポンスのパターン
- イベントメッセージ
- 機能ごとの通信ルール

## 典型的な利用フロー

一般的なクライアント連携は、次の流れに従います。

1. クライアントがRomiにリクエストメッセージをpublishします。
2. Romiがリクエストを処理します。
3. リクエスト処理結果をRomiがレスポンスとして返します。
4. 非同期通知が必要な場合、Romiがイベントをpublishします。
